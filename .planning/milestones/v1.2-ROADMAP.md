# Roadmap: v1.2 Connector Label Writing

## Goal

Add safe AFFiNE connector label writing so the CLI can prepare, review, and apply text labels to existing arrows on Canvas diagrams.

## Phase Sequence

1. Phase 5: Connector Label Snapshot Model And Search
2. Phase 6: Connector Label Plan Contract
3. Phase 7: Gated Connector Label Live Apply
4. Phase 8: Workflow Proof, Docs, And Publish Durability

## Dependencies

- v1.1 `canvas search` connector extraction.
- v1.1 `canvas diff` semantic categories.
- v1.1 `canvas transform` plan shape and live apply gates.
- AFFiNE `affine:surface.prop:elements` connector representation.

## Exit Criteria

- Operators can identify existing connectors, prepare label changes, review before/after values, and apply them live with proof.
- The command path preserves current card geometry and connector endpoints.
- UTF-8 label text survives plan generation and live apply.
- The final workflow is documented in CLI help and project planning artifacts.
